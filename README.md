## 📌 درباره پروژه

این مخزن شامل وب‌سایت پورتفولیوی شخصی من است که با هدف معرفی مسیر من به‌عنوان یک توسعه‌دهنده فرانت‌اند طراحی و توسعه داده شده است.

این وب‌سایت **به‌صورت کامل از صفر و بدون استفاده از فریم‌ورک‌های CSS** ساخته شده و تمرکز اصلی آن روی ساختار تمیز، طراحی ریسپانسیو، المان‌های تعاملی، دسترسی‌پذیری و ایجاد تجربه کاربری روان است.

همچنین این پروژه برای من یک محیط عملی است تا مفاهیمی را که در مسیر یادگیری توسعه فرانت‌اند یاد می‌گیرم، در یک پروژه واقعی پیاده‌سازی و به مرور بهبود دهم.

## 📌 About the Project

This repository contains my personal portfolio website, designed and developed to present my journey as a front-end developer.

The website was built **from scratch without using CSS frameworks**, with a focus on clean structure, responsive layouts, interactive elements, accessibility, and a smooth user experience.

It also serves as a practical project where I continuously apply and improve the concepts I learn throughout my front-end development journey.

---

## ✨ Features

* 📱 Fully responsive design for mobile, tablet, and desktop
* 🌐 Persian / English language support
* 🎨 Custom UI built entirely with HTML & CSS
* ⚡ Interactive elements powered by JavaScript
* 🖱️ Draggable horizontal skills slider
* 📂 Interactive project cards with detailed information
* 🧭 Learning journey timeline
* 👁️ Scroll-based reveal animations using `IntersectionObserver`
* 🔗 Social media and contact links
* 📐 Responsive layout optimized for different screen sizes
* 🧩 Component-like structure and reusable CSS classes
