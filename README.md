# 🌐 پورتفولیوی رضا

یک وب‌سایت شخصی و ریسپانسیو که از صفر ساخته شده تا خودم، مهارت‌ها، مسیر یادگیری و پروژه‌هایم را معرفی کنم.

این پروژه **اولین پروژه واقعی من است که تصمیم گرفتم آن را در GitHub منتشر کنم**. این وب‌سایت را همزمان با یادگیری و تقویت مهارت‌هایم در توسعه Front-end طراحی و پیاده‌سازی کردم.

در طول توسعه، برای **یادگیری، پیدا کردن بعضی خطاها، رفع باگ‌ها و بهبود بخش‌هایی از کد** از هوش مصنوعی به عنوان یک دستیار استفاده کردم.

با این حال، طراحی، ساختار پروژه، پیاده‌سازی نهایی و تصمیمات مربوط به کد توسط خودم انجام شده و تمام تغییرات نیز توسط خودم بررسی و تست شده‌اند.

# 📌 درباره این پروژه

این پروژه یکی از قدم‌های مهم من در مسیر یادگیری Front-end Development است.

هدف این پروژه ساخت یک محصول کاملاً بی‌نقص یا نهایی نبوده؛ بلکه نشان‌دهنده چیزهایی است که تا امروز یاد گرفته‌ام، مشکلاتی که در طول توسعه با آن‌ها روبه‌رو شده‌ام و راه‌هایی است که برای حل آن‌ها پیدا کرده‌ام.

این پروژه را ساختم تا خودم را به چالش بکشم، چیزهایی را که یاد گرفته‌ام در یک پروژه واقعی به کار ببرم و در نهایت چیزی داشته باشم که بتوانم آن را با دیگران به اشتراک بگذارم.

# 🌐 Reza Portfolio

A responsive personal portfolio website built from scratch to introduce myself, showcase my skills, learning journey, and projects.

This is my **first real project that I decided to publish on GitHub**. I designed and developed it while learning front-end development and improving my HTML, CSS, and JavaScript skills.

# ✨ Features

* Fully responsive design for desktop, tablet, and mobile
* Modern dark-blue themed UI
* Animated hero section
* Interactive skills section
* Animated skill progress indicators
* Personal "About Me" section
* Learning journey timeline
* Contact section with interactive modal
* Smooth animations and transitions
* Responsive navigation
* Optimized image assets
* GitHub Pages deployment

# 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

# 📚 What I Learned

Building this project helped me improve my understanding of:

* Responsive web design
* CSS positioning and layouts
* CSS animations and transitions
* JavaScript DOM manipulation
* Event handling
* Intersection Observer API
* Creating interactive UI components
* Organizing a real-world front-end project
* Git and GitHub workflow
* Deploying a website using GitHub Pages
